# 桌面界面与交互契约

**依据**：[spec.md](../spec.md)、最终评审 DEMO。只针对桌面；没有移动端适配/验收任务。

## 一、复盘主界面

1. 原 market/rotation 两步合并为 market：“市场与板块”。新闻总结、操作计划、深度总结的相对顺序不变；操作计划账户分组不变。
2. 直接在“市场与板块”标题右侧放添加标的、自动排序、上移、下移、删除工具栏；不得再添加“市场标的 / N 个标的”分组标题。
3. 表格列为：标的、支撑位、压力位、思考、其他分析。保留短摘要与现有长文本 tooltip，不按正文长度撑成多张卡片。
4. 标的列显示代码和名称；同名代码/名称可以省略重复名称。US10Y 显示十年期收益率，内部键 TNX。每标的左侧浅蓝竖条接近行高（上下各留 12px），选中行深蓝；不要整张表的连续外围蓝线。列表不显示共用价位说明，仅详情弹窗显示。市场详情与标的选择均为居中弹窗，详情与操作计划同宽同款输入样式，标题右侧只显示当前最近价格与复盘日涨跌幅。
5. 表格样式沿用 action-plan-table 的字重、行高、浅灰表头、选中背景、文本颜色与按钮。列宽按这五列内容调整，不复用其八列 colgroup 导致大量空白。
6. 标的关联计划时显示账户同步提示；没有计划仍允许标的主题与价位存在。不要把“同步”理解为调用券商或执行交易。
7. 点击行/目录条目打开对应详情并选中；键盘 Enter/Space 可打开，Esc 关闭；排序依据稳定 block id，不依赖当前数组索引识别身份。
8. 删除一级需确认；删块/二级只移除市场视图，不删除计划价位。自动排序按目录分组、sort_order、symbol，未关联历史块保持原相对顺序放末尾；手动排序仍可覆盖自动排序。

## 二、详情面板

- 右侧面板显示当前标的与名称，复用真实操作计划字段卡片、输入框、关闭按钮和吸底操作区视觉。仅本功能面板右侧布局，不顺手改变现有操作计划 modal 位置。
- 使用当前复盘日行情目录中已有 metrics 时可展示；无行情显示暂无，不新增网络采集。若 metrics 不加载也不阻断编辑。
- 支撑位/压力位并排编辑；思考、CTA、JPM collar、EPS 等长内容按宽行显示；自定义字段按二级顺序呈现。
- 预设标题固定，自定义标题可编辑；添加菜单中已有预设禁用，自定义可多个。二级只保留删除，按添加顺序展示，不提供上移/下移。
- 写价位调用共用的本地 symbolLevels 更新入口；市场 textarea 和计划 textarea 不各自维护互不联动的副本。编辑共用值后更新所有同标的账户行。
- 若计划中填非空价位而市场缺少该标的/二级，追加并显示。保存没变的老价位、仅排序、改仓位或删除计划不自动重建已删市场主题。
- 更换已含支撑/压力二级的标的被拒绝；重复目标提示并定位，保留原草稿。
- 所有“完成编辑”操作只是更新该复盘的本地草稿；持久化由现有顶部保存/完成复盘负责，不给每个二级加自动提交网络请求。
- 关闭允许保留本地已输入内容，与当前复盘编辑语义保持一致；不扩展撤销/版本恢复功能。
- 价位冲突显示采用来源、未采纳原文和当前值；历史证据不是可编辑的第二份共用价位。

## 三、标的选择

复用现有操作计划选择器的搜索、分组、过滤按钮和结果样式。全部启用标的可选（不按是否有行情过滤）；搜索涵盖代码、displayCode、显示名称、别名。

- 新标的默认包含支撑位、压力位、思考。
- 已有价位直接带入；已有主题提示“已添加”，再次选择定位而非覆盖。
- 目录失败只显示提示并禁用新增/更换标的，不清空草稿，无“重试目录”按钮；状态行无消息时隐藏。历史标的不可用显示状态，新建不允许手输假身份。

## 四、历史内容与只读

- 未关联历史块在同一入口的独立历史列表展示原标题/原文，不能伪装成管理标的。可展开查看、删除确认或关联标的，不允许直接编辑原文。
- 只读查看禁用两处价位输入，隐藏/禁用添加、排序、删除、预设修改；查看详情、目录、导出仍可用。
- 点击“查看”只发 GET，不执行归并写库；进入编辑也不自动保存。
- 显式保存为空后，重开不能出现旧列复活的一级主题。

## 五、导出与其他页面

顶部原导出画线入口保留，读取新统一内容，不新增重复按钮；GSPC 专用模板保持原传参、负伽马、CTA 加速点及压力不导出规则。普通标的共用价位压力在前、支撑在后、重复去重。账户管理原导出入口不变。

标的管理中 TNX 行展示 US10Y 并保留内部键提示；没有新增 US10Y 行，没有标的类别重构。操作计划除两项价位来源变化外，不改字段、账户分组、仓位和金额操作。

## 六、桌面验证尺寸

在 1440×1000 与 1920×1080 桌面窗口验证主表和详情：工具栏完整可点、长中文标题/正文可读、内容滚动与吸底区不遮挡、所有字段可访问。不新增 390px 手机验收，也不为手机专门重排字段。
